# Tokenizer Playground

An interactive web application built with **Next.js, React, TypeScript, and Hugging Face Transformers.js** to explore how AI models convert text into tokens.

## Features

- Select different tokenizer models.
- Enter custom text for tokenization.
- View token count, word count, and character count.
- Visualize tokens with different colors.
- Display individual Token IDs.
- Switch between Text, Token IDs, and Hide views.
- Load custom Hugging Face tokenizer models.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Hugging Face Transformers.js
- CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/nur21horin/token_play_ground.git
cd token_play_ground
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
Live link: https://tokenplayground-five.vercel.app/

## Build

```bash
npm run build
npm start
```

## Security

- Never commit API keys or secrets.
- Keep environment variables private.
- Do not commit `.env` files or generated `.next` files.
